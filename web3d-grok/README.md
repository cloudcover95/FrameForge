# web3d-grok

FrameForgeUE5 HTML5 hybrid. Three.js display. Sim is JS, legal floor shared with FrameForge2D.
Blender display emit is optional via `blender_ext/jc_blender.py` (shared JuniorCloud host).

```
python3 -m http.server 8766 --directory web3d-grok
node web3d-grok/check.mjs
python3 blender_ext/jc_blender.py frameforge-display blender_out 0
```
